# Transfer-Learning
Transfer Learning will be the next major driver of commercial success in machine learning, right after supervised learning. - Andrew NG
<br>
read the code for better understanding.
Overall process in one view:
<br>step 1: import the libraries.

<br>step 2: Load the dataset and split into training, testing and validation data.
<br>step 3: do preprocessing of the data according to the pretrained model (in this case pretrained model is VGG16).
<br>step 4: load the pretrained model and create our model.
<br>step 5: compile the model and train it.
<br>step 6: evaluate the model.
